# 系统调用入口

v0.1 · 2026-08-29

本篇覆盖：`kernel/system/syscall.c`（weak）、`arch/x86_64/trap/kernel_entry.S`、`arch/x86_64/boot/start_arch.c`（`init_syscall` / MSR）、`arch/aarch64/boot/start_arch.c`（`arch_syscall_helper` + `register_fixed_trap`）、`include/arch/*/trap/trap.h` 参数宏、`arch/*/task/arch_thread.c` 里 Path A 返回助手（点到为止）。

Trap 双入口总图与 schedule 表见 `Trap抽象与分类.md`；Path A/B 与 `arch_return_to_user` 细节见 `线程创建与ELF加载.md`。本篇**不**写 APIC/GIC/Timer。

## 1. 概述

core **不做** Linux syscall 表。它只保证：用户用架构指令进内核时，拿到可读写的上下文指针，再调到一个**可被链接覆盖**的 `syscall(tf)`。

两条硬件路，别写成一条。

| | x86_64 | aarch64 |
|--|--------|---------|
| 硬件门 | `syscall` → **IA32_LSTAR** | `svc` → VBAR Sync → **`trap_handler`** |
| 与 trap 框架 | **旁路**（不经 `trap_handler`） | **走** `irq_vector[EC]` + `TRAP_CLASS_SYSCALL` |
| 末尾自动 `schedule` | **否** | **是**（用户来源） |
| boot 注册 | 写 STAR/FMASK/LSTAR | `register_fixed_trap(SYSCALL, arch_syscall_helper, …)` |

旧稿写「两 arch 都 register_fixed_trap(SYSCALL)」或「x86 也走 sysenter」——**错**。实现只有 **syscall/sysret**；x86 的 `x86_trap_class_map` **无** SYSCALL 项。

---

## 2. 目标与边界

**提供：** weak `syscall` 挂钩；两 arch 进核帧约定；中断标志继承策略说明；参数/返回值宏；与 Path A 返回的边界。

**不做：** NR_syscalls、seccomp、strace、vsyscall、int 0x80（未接）。fork/exec 特殊返回由 compat 在 `syscall` 内自管。

---

## 3. 分层与调用方

**兼容层** — 强符号覆盖：

```c
void syscall(struct trap_frame *tf)
{
        /* 读 ARCH_SYSCALL_ID / ARG*，写 ARCH_SYSCALL_RET */
}
```

须在用户跑起来前链接进镜像。**不要**在 linux_layer 再做 aarch64 DAIF inherit——只在 `arch_syscall_helper`。

**core 测例** — 无强符号时 weak 为空；用户 SVC/`syscall` 无 ops。

---

## 4. 数据结构与不变量

### 4.1 弱符号

```c
__attribute__((weak)) void syscall(struct trap_frame *syscall_ctx);
```

返回值写 **frame 槽**（`ARCH_SYSCALL_RET`），不是依赖 C 函数返回后的 `%rax`/`x0`——x86 exit 从栈上 rax 槽恢复。

### 4.2 参数宏

| | ID | RET | ARG1–6 |
|--|----|-----|--------|
| x86 | `rax` | `rax` | `rdi,rsi,rdx,r10,r8,r9` |
| aarch64 | `REGS[8]` (x8) | `REGS[0]` | `REGS[0..5]` |

aarch64：ARG1 与 RET **同槽 x0**——先读参再写返回值。

### 4.3 x86 syscall_ctx ≠ 完整 iret 帧

入口拼「类 trap_frame」前部；**不填**完整 `trap_info` / rip/cs/… 尾。用户 PC 在硬件 **RCX**（入口保存）；用户 SP 在 **`percpu(user_rsp_scratch)`**，不是 `tf->rsp`。Path A 只依赖重叠寄存器区 + scratch。

### 4.4 aarch64

EC **0x15**（EL0 SVC）、**0x18**（same-EL 防御）绑 fixed wrapper。`tf->SP` = 异常后的 **内核栈指针**，**不是**用户 SP——用户 SP 走 `SP_EL0` / `arch_syscall_set_user_return`。

## 6. 流程

### 6.1 x86（MSR 旁路）

每核 `arch_start_core`：`init_interrupt` → … → **`init_syscall`** → **`arch_enable_irq`**。

1. **IA32_STAR**：`KERNEL_CS<<32` + `GDT_TSS_UPPER*8<<48`（靠 `+16/+8` 算术落到 USER_CS/DS，不是直接写 USER_CS 字面）。  
2. **IA32_FMASK = 0x200**：进核清 **IF**。  
3. **IA32_LSTAR** → `arch_enter_kernel`。

```text
syscall → swapgs、切 DS/ES、TSS 内核栈
  → 压类 trap_frame 前部；rdi=rsp
  → sti
  → call syscall
  → cli → 恢复 → scratch RSP → swapgs → sysretq
```

**不**经 IDT / `trap_handler` / EOI / 统一 `schedule`。

### 6.2 aarch64（SVC + helper）

须先 `init_interrupt`（EC 槽 USED），再 `init_syscall`：

```c
register_fixed_trap(TRAP_CLASS_SYSCALL, arch_syscall_helper, IRQ_NO_ATTR);
```

```text
svc → VBAR Sync → trap_info=ESR.EC → trap_handler
  → fixed wrapper → arch_syscall_helper:
       EL0: 保存 DAIF → inherit SPSR.I → syscall(tf) → 恢复 DAIF
  → 无 EOI → 用户来源则 schedule → eret
```

每核都调 `register_fixed_trap`（写全 CPU 槽，幂等覆盖）。

### 6.3 中断窗口：sti vs DAIF（勿称完全等价）

| | x86 | aarch64 |
|--|-----|---------|
| 入口硬件 | FMASK 清 IF | 异常入口 DAIF 全屏蔽 |
| syscall 窗口 | 入口 **无条件 `sti`** | EL0：**只继承 user SPSR.I** |
| 出口 | `cli` + sysret 恢复 RFLAGS | 恢复 saved DAIF；用户 I 仍在 SPSR |

若 user 进核前 I 已屏蔽：aarch64 保持屏蔽，x86 `sti` 仍打开。

### 6.4 返回用户（边界）

| | Path A（syscall 返回） | Path B（首次 drop） |
|--|------------------------|---------------------|
| API | `arch_syscall_set/get_user_return` | empty drop + set + **`arch_return_to_user`** |
| x86 | rcx=pc, rax=ret, scratch/sp | `arch_drop_to_user` |
| aarch64 | ELR/REGS[0]/SP_EL0；`tf->SP=(vaddr)tf` | 同左再 drop |

**禁止**对正在 Path A 返回的线程再调 `arch_return_to_user`。

### 6.5 schedule 不对称（主不变量）

| 路径 | 统一末尾 schedule？ |
|------|---------------------|
| x86 `syscall` 指令 | **否**（除非 `syscall()` 内自调） |
| aarch64 用户 SVC | **是**（经 `trap_handler`）→ 顺带 kfree/EBR 排水 |

## 7. 公开 API

```c
void syscall(struct trap_frame *syscall_ctx);  /* weak；compat 强覆盖 */

/* arch 宏：ARCH_SYSCALL_ID / RET / ARG1..6 */
void arch_syscall_set_user_return(...);
u64 arch_syscall_get_user_return(...);
```

`init_syscall` 为 arch boot 内部，非上层 API。
