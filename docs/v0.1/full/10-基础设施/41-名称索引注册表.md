# 名称索引注册表

v0.1 · 2026-08-29

本篇覆盖：`kernel/registry/name_index.c`、`include/rendezvos/registry/name_index.h`。

Port 表消费见 Port 篇；线程 port LRU 见 TM 篇；MCS 双 `me` 见锁篇。

**纠正：** VSpace 注册树是 **rb_tree + CAS**，**不是** name_index。今日生产实例基本只有 **`global_port_table.by_name`**——原语可复用，不是「多实例广泛复用」。

---

## 1. 概述

**`name_index_t`**：字符串键 → 对象指针的注册表。行数组（slot + generation）+ 开放寻址哈希 + MCS 锁；可选 hold/drop、on_register/unregister；**token**（`row_index` + `row_gen`）供无锁外缓存后 `resolve`。

给 port 名做 O(1) 均摊查找；不是层级命名空间。

---

## 2. 目标与边界

**提供：** register / lookup / resolve / unregister；HT grow/shrink；钩子。

**不做：** 通配、路径层级、per-thread cache（在 `Thread_Base`）；同名查重（**name_index 层可插两行同名**——**port 层**先 `search` 再拒）。

---

## 3. 分层与调用方

| 入口 | 谁加锁 | percpu `me` |
|------|--------|-------------|
| `register_port` / `unregister` / `port_is_live` | **port 层**持 `by_name.lock`，再调无锁的 search/register/unregister | `port_table_spin_lock` |
| `name_index_lookup` / `resolve` / `fini` | **name_index 内部** | `name_index_spin_lock` |

对 **同一把** `by_name.lock`、两套 `me`——合法，但 **同 CPU 禁止嵌套两条入口**（双节点自死锁）。

Token 缓存：`thread_lookup_port` 热路径 `resolve`。

---

## 4. 数据结构与不变量

- 行：`EMPTY=-1` / `TOMB=-2` / row_idx；freelist。  
- Token：`{u32 row_index; u16 row_gen}`；行内 `gen` 是 **u64**，比时截 **u16**（长期 unregister 理论别名风险）。  
- 初始 rows 32、ht 64；port `name_len_max=64`。  
- HT live >70% grow；load≤25% 且 tomb≥10% shrink。  
- **register/unregister/search 自身不加锁**（假定调用方已持锁）；lookup/resolve **内部加锁** + optional hold。  
- hold 成功后 caller 必须 drop。

钩子：`get_name` / `hold` / `drop` / `on_register` / `on_unregister` + `owner_context`。

---

## 6. 流程

Cold：`name_index_lookup(idx, name, &tok)` → hold。  
Hot：`resolve(idx, tok, …)` 校验 gen。  
Register（port）：锁内 search → 冲突 `-E_RENDEZVOS` → `name_index_register`。  
Unregister：需正确 `row_idx`+`name`；port 在 unlock 后还做 ops drain（Port 篇）。

---

## 7. 公开 API

```c
error_t name_index_init(...);
void name_index_fini(...);
error_t name_index_register / register_abort / unregister(...); /* 无锁 */
void *name_index_search(...); /* 无锁无 hold */
void *name_index_lookup / resolve(...); /* 内部加锁 */
```
