# 名称索引注册表

v0.1 · 2026-09-26

本篇覆盖：`kernel/registry/name_index.c`、`include/rendezvos/registry/name_index.h`。

Port 表消费见 `18-Port与消息模型.md`；线程 port LRU / token 见 TM 篇；MCS 双 `me` 禁忌见锁篇。

**纠正：** VSpace「按名注册」是 **rb_tree + CAS**，**不是** name_index。今日生产实例基本只有 **`global_port_table.by_name`**——原语可复用，不是「多实例广泛复用」。

本篇几乎无板级硬件；并发接点是 **MCS 锁 + per-CPU `me` 节点**。

---

## 1. 概述

`name_index_t`：字符串键 → 对象指针的扁平注册表。实现是 **行数组**（slot + generation）+ **开放寻址哈希** + 一把 MCS 锁；可选 hold/drop、on_register/unregister；**token**（`row_index` + `row_gen`）供无锁外缓存后 `resolve`。

给 port 名做均摊 O(1) 查找；不是层级命名空间，没有通配。

### 1.1 为什么要 token

热路径（`thread_lookup_port`）不想每次 strcmp 扫字符串。缓存 `(row_index, row_gen)`，下次 `resolve` 校验 generation——行被 unregister 再复用时 gen 变，旧 token 失效。

---

## 2. 目标与边界

**提供：** register / lookup / resolve / unregister；HT grow/shrink；钩子。

**不做：** 通配、路径层级、per-thread cache（那在 `Thread_Base`）；同名查重（**name_index 层可插两行同名**——**port 层**先 `search` 再拒）。

---

## 3. 分层与调用方

| 入口 | 谁加锁 | percpu `me` |
|------|--------|-------------|
| `register_port` / `unregister` / `port_is_live` | **port 层**持 `by_name.lock`，再调**无锁**的 search/register/unregister | `port_table_spin_lock` |
| `name_index_lookup` / `resolve` / `fini` | **name_index 内部** `lock_mcs` | `name_index_spin_lock` |

对**同一把** `by_name.lock`、两套 `me`——合法（MCS 要求 `me` 是当前 CPU 的节点），但 **同 CPU 禁止嵌套**两条会抢同一把锁的入口（双节点自死锁）。详见锁篇。

Token 缓存：`thread_lookup_port` 热路径优先 `resolve`。

---

## 4. 数据结构与不变量

- 行：`used` 0/1；空闲链；HT 桶值 `EMPTY=-1` / `TOMB=-2` / row_idx。  
- Token：`{u32 row_index; u16 row_gen}`；行内 `gen` 是 **u64**，写出 token 时截 **u16**（长期 unregister 理论别名风险）。  
- 初始 rows 32、ht 64；port 侧 `name_len_max=64`。  
- 哈希：FNV-1a 风格；probe 线性。  
- HT：live &gt;70% grow；load≤25% 且 tomb 足够多时 shrink。  
- **register / unregister / search 自身不加锁**（假定调用方已持锁）；lookup / resolve **内部加锁** + optional hold。  
- hold 成功后 caller 必须 drop（port 用 refcount 钩子）。

钩子：`get_name` / `hold` / `drop` / `on_register` / `on_unregister` + `owner_context`。

## 6. 流程

```text
Cold:  name_index_lookup(idx, name, &tok)  → 内部加锁 + hold
Hot:   name_index_resolve(idx, &tok, name) → 校验 gen + hold
Register(port):
  持 by_name.lock
  search → 已有同名则 -E_RENDEZVOS
  name_index_register → on_register
Unregister:
  持锁 → unregister(row_idx, name) → unlock 后 ops drain（Port 篇）
```

```c
void name_index_init(...);

error_t name_index_register(...);           /* 无锁 */

void *name_index_search(...);               /* 无锁，无 hold */
void *name_index_lookup / resolve(...);     /* 内部加锁 */
```
