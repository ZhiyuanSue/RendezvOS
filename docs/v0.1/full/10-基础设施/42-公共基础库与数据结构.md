# 公共基础库与数据结构

v0.1 · 2026-10-02

本篇覆盖：`include/common/**`（重点 DSA / refcount / types / atomic / string）、`kernel/mm/string.c`。

MSQ 算法细节 → `22-无锁队列与EBR设计.md`；atomic / MCS → `31-锁与内存屏障.md`；timer / VSpace 如何用 rb → 各子系统篇。  
**不**展开 `include/arch/*/sys_ctrl`、cpuinfo、SBI——一句：ISA 寄存器与特权指令在 arch 头，本篇不写。

---

## 1. 概述

`common/` 提供 **无业务语义** 的积木：定宽类型、原子、侵入式链表/树/位图、引用计数、字符串子集。线程 / VSpace / Port **不**住在这里。

可复用容器与原语；没有 malloc，没有 printf（打印 → log；堆 → kmalloc）。

---

## 2. 目标与边界

**提供：** §4 分级表中的组件。  
**不做：** 完整 libc；格式化 IO；堆分配器；OF / 驱动框架；第二套「通用对象模型」。

新代码优先复用 DSA，不要再发明第二套链表 / 哈希。

---

## 3. 分层与调用方

全核：调度环用 list；timer 与 **VSpace 注册树**用 rb；ASID / tlb mask 用 bitmap；IPC 用 MSQ + taggedptr + refcount；字符串拷贝用 `string.h`（实现在 `kernel/mm/string.c`）。

---

## 4. 数据结构与不变量（分级）

### 4.1 值得钉职责

| 头 | 要点 |
|----|------|
| `refcount.h` | `ref_init` / `ref_get_not_zero` / `ref_get_claim` / `ref_put`；防复活；贯穿 port / message / EBR |
| `taggedptr.h` | MSQ / thread_queue 指针打 tag |
| `dsa/ms_queue.h` | Michael–Scott；头文件厚；算法 → 04 |
| `dsa/list.h` | intrusive 双向 |
| `dsa/rb_tree.h` | 自实现 RB；timer、**VSpace 注册树**（**不是** name_index） |
| `dsa/bitmap.h` | `BITMAP_DEFINE_TYPE`；ASID 等 |
| `types.h` | `u8..u64`、`vaddr`/`paddr`、`error_t`、`asid_t`… |
| `atomic.h` | + arch `atomic.c`（与屏障篇衔接） |
| `string.h` | 最小集；实现在 **`kernel/mm/string.c`**（不在 modules） |

### 4.2 简表即可

`bit.h`、`align.h`、`endianness.h`、`mm.h`（VPN/PPN 宏）、`spin.h`（极薄）、`dsa/tree.h`（device / pci 父子树）。

**字节序政策：** 全支持架构（x86_64 / aarch64 / …）按 **小端（LE）** 构建与运行；**不做**大端适配层。FDT / 部分固件表在线上是 **大端**，读属性时经 `endianness.h`（`be32_to_cpu` 等）换成宿主序——这是「外来 blob 解码」，不是「内核改 BE」。详见 DTB 篇对 `property_read_*` 的用法。

### 4.3 勿展开

`stdbool` / `stddef` / `stdarg` / `limits` / `assemble` / `rand`。

早期 `nexus.h` 已删除；用户映射走 `vmm_radix_tree` / `mm_user_utils`。历史名 `tcb.h` 以当前线程头为准。

## 7. 公开 API

本篇拥有：`include/common/**` 中**无业务语义**的积木盘点与下列头的约定说明——`types.h`、`refcount.h`、`string.h`、`dsa/list.h`、`dsa/rb_tree.h`、`dsa/bitmap.h`、`dsa/tree.h`，以及简表组件（`bit`/`align`/`endianness`/`mm` 宏）。以头文件注释为准（见各头；已抽查与用法一致）；**不**在本篇复述全量签名。

**本篇不拥有：** `ms_queue.h` / `taggedptr.h` 算法 → `22`；`atomic.h` / 屏障与 MCS → `31`；`Error_t` 码表语义 → `40`；业务如何挂 list/rb（timer / VSpace / sched）→ 各子系统篇。

### 7.1 编排约定（调用方须遵守）

| 场景 | 用法 |
|------|------|
| 对象生命周期 | `ref_init` / `ref_get_not_zero` / `ref_put(free_fn)`——防 0→正「复活」 |
| 调度 / 同到期 | intrusive **`list.h`** |
| 有序键 | **`rb_tree.h`**（timer、VSpace 注册树——**不是** name_index） |
| 位图 | **`BITMAP_DEFINE_TYPE`**（ASID 等） |
| 设备 / PCI 树 | **`tree.h`**（父子 sibling，非搜索树） |
| 字符串 | `string.h` API；实现在 **`kernel/mm/string.c`** |

新代码优先复用，勿再发明第二套链表/哈希。

### 7.2 本篇钉职责的头（入口）

| 头 | 要点 |
|----|------|
| `types.h` | `u8..u64`、`vaddr`/`paddr`、`asid_t`、`error_t` |
| `refcount.h` | `ref_init` / `_zero` / `get_not_zero` / `get_claim` / `put` / `ref_count` |
| `string.h` | `memset`/`memcpy`/`strlen`/`strcmp`/`strcmp_s`/`strncpy` |
| `dsa/list.h` | `INIT_LIST_HEAD` / `list_add_*` / `list_del*` / `list_empty`… |
| `dsa/rb_tree.h` | `RB_Link_Node` / `RB_SolveDoubleRed` / `RB_Remove` / First·Next… |
| `dsa/bitmap.h` | `BITMAP_DEFINE_TYPE` / `BITMAP_OPS` |
| `dsa/tree.h` | `tree_node_insert` / `tree_node_get_next` |

### 7.3 简表 / 勿展开

`bit.h`、`align.h`、`endianness.h`、`mm.h`（VPN/PPN）、`spin.h`（仅 `cpu_idle`）。  
`stdbool`/`stddef`/`stdarg`/`limits`/`assemble`/`rand`——不单开约定说明。

### 7.4 语义以他篇为准（勿在本篇改写）

| 头 | 归属 |
|----|------|
| `dsa/ms_queue.h`、`taggedptr.h` | `22` |
| `atomic.h`（+ arch `atomic.c`） | `31` |
