# 公共基础库与数据结构

v0.1 · 2026-10-02

本篇覆盖：`include/common/**`（重点 DSA（Data Structure Abstractions，数据结构抽象）/ refcount / types / atomic / string）、`kernel/mm/string.c`。

MSQ（Michael-Scott Queue，无锁队列）算法细节 → `22-无锁队列与EBR设计.md`；atomic / MCS → `31-锁与内存屏障.md`；timer / VSpace 如何用 rb → 各子系统篇。
**不**展开 `include/arch/*/sys_ctrl`、cpuinfo、SBI（Supervisor Binary Interface，RISC-V 监管模式二进制接口）——一句：ISA 寄存器与特权指令在 arch 头，本篇不写。

---

## 1. 概述

`common/` 提供 **无业务语义** 的积木：定宽类型、原子、侵入式链表/树/位图、引用计数、字符串子集。线程 / VSpace / Port **不**在此处。

可复用容器与原语；没有 malloc，没有 printf（打印 → log；堆 → kmalloc）。
---

## 2. 目标与边界

**提供：** §4 分级表中的组件。
**不做：** 完整 libc；格式化 IO；堆分配器；OF（Open Firmware，开放固件/设备树）/ 驱动框架；第二套「通用对象模型」。

新代码优先复用 DSA，不要再发明第二套链表 / 哈希。

---

## 3. 分层与调用方

全核：调度环用 list；timer 与 **VSpace 注册树**用 rb；ASID / tlb mask 用 bitmap；IPC 用 MSQ + taggedptr + refcount；字符串拷贝用 `string.h`（实现在 `kernel/mm/string.c`）。

---

## 4. 数据结构与不变量（分级）

### 4.1 需明确职责的头

| 头 | 要点 |
|----|------|
| `refcount.h` | `ref_init` / `ref_get_not_zero` / `ref_get_claim` / `ref_put`；防复活；贯穿 port / message / EBR |
| `taggedptr.h` | MSQ / thread_queue 指针打 tag |
| `dsa/ms_queue.h` | Michael–Scott；头文件较大；算法 → 04 |
| `dsa/list.h` | intrusive 双向 |
| `dsa/rb_tree.h` | 自实现 RB；timer、**VSpace 注册树**（**不是** name_index） |
| `dsa/bitmap.h` | `BITMAP_DEFINE_TYPE`；ASID（Address Space ID，地址空间标识）等 |
| `types.h` | `u8..u64`、`vaddr`/`paddr`、`error_t`、`asid_t`… |
| `atomic.h` | + arch `atomic.c`（与屏障篇衔接） |
| `string.h` | 最小集；实现在 **`kernel/mm/string.c`**（不在 modules） |

### 4.2 简表即可

`bit.h`、`align.h`、`endianness.h`、`mm.h`（VPN/PPN 宏）、`spin.h`（极薄）、`dsa/tree.h`（device / pci 父子树）。

**字节序政策：** 全支持架构（x86_64 / aarch64 / …）按 **小端（LE）** 构建与运行；**不做**大端适配层。FDT（Flattened Device Tree，扁平设备树）/ 部分固件表在线上是 **大端**，读属性时经 `endianness.h`（`be32_to_cpu` 等）换成宿主序——这是「外来 blob 解码」，不是「内核改 BE」。详见 DTB 篇对 `property_read_*` 的用法。

### 4.3 勿展开

`stdbool` / `stddef` / `stdarg` / `limits` / `assemble` / `rand`。

早期 `nexus.h` 已删除；用户映射走 `vmm_radix_tree` / `mm_user_utils`。历史名 `tcb.h` 以当前线程头为准。

### 4.4 算法要点（背景）

#### refcount 原子操作与释放语义

```text
refcount 状态机（原子计数）：
  ref_init(n)         count = n
  ref_get_not_zero    if (count != 0) { count++; return true; }
                      else return false;        // 复活防护：0 时无法获取
  ref_get_claim       占位申领（不增加实际引用）
  ref_put(free_fn)    if (--count == 0) free_fn(obj);  // 末次引用负责释放

  复活防护链：
    count 0→正 必须经过 ref_get_not_zero；
    put 到 0 后他人无法再 get（not_zero 见 0 即失败），
    除非重新 init——而 init 由分配者独占保证。
  贯穿 port / message / EBR（Epoch-Based Reclamation，基于世代的回收）：释放语义统一靠这套，不再各自实现一套。
```

#### rb_tree 插入与旋转

```text
插入：按 BST（Binary Search Tree，二叉搜索树）找位置 → 新节点染红 → 可能违反「红红相邻」
修复（RB_SolveDoubleRed）：
  叔黑 + 父红：
    LL / RR → 单旋（父转黑、爷转红）
    LR / RL → 双旋（先旋父，再旋爷）
  叔红：父/叔转黑、爷转红，向上迭代（重染色，不旋转）
删除：BST 替换 → RB_Remove 调整黑高

  单旋示例（LL，左左）：
        G(r)                  P(b)
       /    \                /    \
     P(r)   U    →    N(r)   G(r)
    /                              \
   N(r)                            U
```

#### list 侵入式节点

```text
侵入式（intrusive）：节点字段嵌在宿主对象里，不独立分配
  struct my_obj { int x; list_node_t link; ... };
  list_add_tail(&obj->link, &head);          // 不分配节点
  obj = container_of(link, my_obj_t, link);  // 反推宿主

  head <-> A <-> B <-> C <-> head   // 双向循环
  list_del(&obj->link)  // 仅摘链，不释放对象（对象由 refcount 管）
```

#### bitmap 位运算技巧

```text
  set bit i:      bitmap[i/64] |=  (1u << (i%64))
  clear bit i:    bitmap[i/64] &= ~(1u << (i%64))
  test bit i:     (bitmap[i/64] >> (i%64)) & 1
  find first 0:   ffs(~word)        // 取反后找第一个置位
  find first 1:   ffs(word)
  BITMAP_DEFINE_TYPE(name, n)      // 生成 uint64 name[(n+63)/64]
  ASID 分配 / TLB mask 均用此。
```

#### endian 转换

```text
  全支持架构（x86_64 / aarch64）按小端（LE）构建运行
  外来 blob（FDT / ACPI 表 / 网络包）常是大端（BE）
  endianness.h 提供：
    be32_to_cpu(x)  // BE→host（LE 上 = byte_swap）
    cpu_to_be32(x)  // host→BE
    le32_to_cpu(x)  // LE→host（LE 上 = no-op）
    cpu_to_le32(x)
  政策：内核本体不改 BE；仅解码外来 BE blob 时转换。
```

### 7.1 编排约定（调用方须遵守）

| 场景 | 用法 |
|------|------|
| 对象生命周期 | `ref_init` / `ref_get_not_zero` / `ref_put(free_fn)`——防 0→正「复活」 |
| 调度 / 同到期 | intrusive **`list.h`** |
| 有序键 | **`rb_tree.h`**（timer、VSpace 注册树——**不是** name_index） |
| 位图 | **`BITMAP_DEFINE_TYPE`**（ASID 等） |
| 设备 / PCI 树 | **`tree.h`**（父子 sibling，非搜索树） |
| 字符串 | `string.h` API；实现在 **`kernel/mm/string.c`** |

新代码优先复用，勿再发明第二套链表/哈希。

## 8. 多架构

类型 / DSA 与 ISA 无关；atomic / barrier 分 arch。

**架构支持现状：** x86_64、aarch64 为当前主线构建目标；riscv64、loongarch64 在 `common/` 与构建配置中仅为占位（部分 arch 头/`atomic.c` 分支可能缺失），尚未作为完整支持架构运行。本篇所述 DSA 与 endian 政策对占位架构同样适用，但实际启用前需补齐对应 arch 层。
