# 公共基础库与数据结构

v0.1 · 2026-08-27

本篇覆盖：`include/common/` 主要头文件、`include/arch/*/sys_ctrl*.h`、`include/arch/*/cpuinfo.h`、`include/arch/*/arch_common.h`、`arch/riscv64/kernel/sbi.c`、`arch/riscv64/kernel/sbi.h`。

各子系统对具体结构的 **用法** 在对应篇（如 MSQ→IPC 篇、rb_tree→定时器篇）；本篇说明 **common 层职责** 与 **跨 arch 占位**。

---

## 1. 概述

**`include/common/`** 提供内核无关的 C 原语：**类型**（`types.h`）、**refcount**、**string**、**atomic**、**DSA**（list、rb_tree、bitmap、ms_queue、tree）、**align/bit/endian**、**mm** 辅助宏等。RendezvOS 刻意 **不** 完整复刻 libc；仅嵌入内核所需子集。

**`include/arch/<isa>/`** — 每 ISA 的 **sys_ctrl**（MSR/MRS 封装）、**cpuinfo**、**arch_common** 常量；与 common 组合供 `kernel/`、`modules/` 使用。

**riscv64 / loongarch** — 仅有 **arch_common** 与 **riscv SBI 桩**；**无完整 bring-up**（v0.1 文档占位）。

---

## 2. 目标与边界

common **不含** RendezvOS 语义（无 `Thread_Base`、无 `VSpace`）。`rendezvos/` 头文件可 include common。

不在 common 实现：完整 `malloc`（在 `kmalloc`）、格式化 IO（在 `log.c`）。

---

## 3. 分层与调用方

| 组件 | 典型 consumer |
|------|----------------|
| `refcount.h` | port、message、thread、vspace |
| `dsa/list.h` | Task_Manager 调度环、timer same_expired |
| `dsa/rb_tree.h` | timer event 树 |
| `dsa/ms_queue.h` | IPC、kmalloc cross-cpu free |
| `dsa/bitmap.h` | buddy、tlb_cpu_mask |
| `dsa/tree.h` | device_node、pci_node |
| `atomic.h` | 全内核 |
| `string.h` | 最小 memcpy/strlen |
| `taggedptr.h` | MSQ（IPC 篇） |

新代码应 **复用** 现有 DSA，避免平行链表实现。

---

## 4. 数据结构与不变量

### 4.1 refcount

`ref_init` / `ref_get_not_zero` / `ref_put`；MSQ 与 IPC 生命周期基础（配合 EBR 延迟 free）。

### 4.2 list_entry / rb_node

Linux 风格 intrusive 结构；container_of 访问宿主。

### 4.3 types.h

`u8`–`u64`、`i64`、`vaddr`/`paddr`、`cpu_id_t` 等；**`error_t`** = `int`。

### 4.4 arch sys_ctrl

x86/aarch64：**`rdmsr`/`wrmsr`/`mrs`/`msr` 宏**、CR/EL 辅助——仅 arch 代码与少量 core 应 include。

---

## 6. 流程

无单一运行时流程；**include 纪律**：

- 内核通用逻辑 → `common/` + `rendezvos/`
- ISA 寄存器 → `arch/<isa>/`
- 模块驱动 → `modules/`

---

## 7. 公开 API

以各头文件注释为准；常用：

- **refcount** — `ref_get`/`ref_put`
- **list** — `INIT_LIST_HEAD`、`list_add_tail`
- **rb_tree** — `RB_Link_Node`、`RB_Remove`
- **bitmap** — bit ops in `bit.h` / `bitmap.h`
