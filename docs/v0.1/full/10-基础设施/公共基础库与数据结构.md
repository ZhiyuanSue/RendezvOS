# 公共基础库与数据结构

v0.1 · 2026-08-29

本篇覆盖：`include/common/**`（重点 DSA / refcount / types / atomic / string）、`kernel/mm/string.c`。

MSQ 算法细节 → 04 无锁篇；atomic/MCS → 06 锁篇；timer/VSpace 如何用 rb → 各子系统篇。  
**不**展开 `include/arch/*/sys_ctrl`、cpuinfo、SBI——一句「ISA 寄存器在 arch 头，本篇不写」。

---

## 1. 概述

common 提供 **无业务语义** 的积木：类型、原子、链表/树/位图、引用计数、字符串子集。线程/VSpace/Port **不**住在这里。

可复用容器与原语；没有 malloc，没有 printf。

---

## 2. 目标与边界

**提供：** 下表组件。  
**不做：** 完整 libc；格式化 IO（→ log）；堆（→ kmalloc）；OF/驱动框架。

---

## 3. 分层与调用方

全核：调度环用 list；timer/VSpace 注册用 rb；ASID/tlb mask 用 bitmap；IPC 用 MSQ+taggedptr+refcount；字符串拷贝用 `string.h`。

新代码优先复用 DSA，不要再发明第二套链表。

---

## 4. 数据结构与不变量（分级）

### 4.1 值得钉职责

| 头 | 要点 |
|----|------|
| `refcount.h` | `ref_init` / `ref_get_not_zero` / `ref_get_claim` / `ref_put`；防复活；贯穿 port/message/EBR |
| `taggedptr.h` | MSQ / thread_queue tag |
| `dsa/ms_queue.h` | Michael–Scott；大头文件；细节 → 04 |
| `dsa/list.h` | intrusive 双向 |
| `dsa/rb_tree.h` | 自实现 RB；timer、**VSpace 注册树**（非 name_index） |
| `dsa/bitmap.h` | `BITMAP_DEFINE_TYPE`；ASID 等 |
| `types.h` | `u8..u64`、`vaddr`/`paddr`、`error_t`、`asid_t` |
| `atomic.h` | + arch `atomic.c` |
| `string.h` | 最小集；实现在 **`kernel/mm/string.c`**（不在 modules） |

### 4.2 简表即可

`bit.h`、`align.h`、`endianness.h`、`mm.h`（VPN/PPN 宏）、`spin.h`（极薄）、`dsa/tree.h`（device/pci 父子树）。

### 4.3 勿展开

`stdbool` / `stddef` / `stdarg` / `limits` / `assemble` / `rand`。

历史遗留：`nexus.h`/`tcb.h` 若树外出现，一句带过即可。
