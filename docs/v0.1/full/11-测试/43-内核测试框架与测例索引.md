# 内核测试框架与测例索引

v0.1 · 2026-08-29

本篇覆盖：`modules/test/test.c`、`single_test.c`、`smp_test.c`、`include/modules/test/test.h` 及各 `single_*` / `smp_*` / `thread_affinity_test.c`。

开关 `RENDEZVOS_TEST` 见构建篇；关机见错误码篇。验证 **core 原语**，不是 compat syscall 回归。

---

## 1. 概述

启用后：**BSP** 跑 `BSP_test` → `single_cpu_test` + `multi_cpu_test` → 常 **`rendezvos_request_poweroff`**；**AP** 只跑 `multi_cpu_test`。

两张静态表，没有构造器自动注册。

| 表 | 行为 |
|----|------|
| `single_test[]` | 顺序；返回值 0=pass |
| `smp_test[]` | 各核并行同 case；BSP barrier（内含 `schedule`）；可选 `check_result()` 时 **忽略**每核返回值 |

槽上限 `MAX_*_TEST_CASE = 10`（single 已约 9、smp 约 8——加测例注意）。

---

## 2. 目标与边界

**提供：** 表驱动框架；barrier；按域索引。  
**不做：** 自动发现；干净 fail-stop 整机（见 §6 注意）；compat 回归。

`pmm_test` 在 single 表 **注释掉**（耗尽显存）。

---

## 3. 分层与调用方

- BSP：`cmain` → `create_test_thread(true)`（`#ifdef RENDEZVOS_TEST`）。  
- AP：`start_secondary_cpu` 路径 `create_test_thread(false)`。  
- 禁用：`OVERRIDE_CFLAGS=-URENDEZVOS_TEST` 或关 json feature。  
- 注册：改 `single_test[]` / `smp_test[]`，无 linker section 魔术。

测例与 boot IPC **非互斥**（boot 可标 suspend）。

---

## 4. 数据结构与不变量

- `test()` 非 0 = fail（多用 `-E_REND_TEST`）。  
- `check_result != NULL`：只 BSP 汇总。  
- `test_state[cpu]` + `curr_test` 同步。

---

## 5. 代码对应

| 路径 | 职责 |
|------|------|
| `test.h` / `test.c` | 框架、barrier、create_test_thread |
| `single_test.c` / `smp_test.c` | 表 |
| 各 `*_test.c` | case |

---

## 6. 流程与失败注意

```text
BSP: single 顺序 → smp 各 case → poweroff
AP: 等 curr_test → 跑 smp case → …
```

**失败非干净收敛：**

- single fail：`break`，可不打印 PASS，但 BSP **仍可能跑** smp 并 **仍 poweroff**。  
- smp fail：BSP `break` 且可能 **不** `curr_test++` → **AP 卡在** `while (curr_test == i)`；BSP 仍可能 poweroff。

不是「失败则整机一致优雅退出」。

## 7. 测例索引（按域）

### Single（`single_test[]`）

| 域 | 入口 / 文件 |
|----|-------------|
| DSA | `rb_tree_test` ← `single_rb_tree_test.c` |
| MM | `arch_vmm_test`；`kmalloc_test`；`page_slice_test`；可选 `pmm_test` |
| 平台 | `test_pci_scan`（`#ifdef PCI`） |
| IPC/Port | `ipc_test`、`ipc_multi_round_test`；`port_discovery` ← `single_port_test.c` |
| 时间 | `single_timer_test` |

### SMP（`smp_test[]`）

| 域 | 入口 | 备注 |
|----|------|------|
| 锁 | `smp_lock_test` + `smp_lock_check` | |
| 堆 | `smp_kmalloc_test` | |
| MSQ | `smp_ms_queue_*`（**三 case 同文件** `smp_ms_queue_test.c`） | 勿捏造独立 dyn/check 文件 |
| IPC/Port | `smp_ipc_test`；`smp_port_robustness_test` | |
| 调度 | `smp_thread_affinity_*` ← `thread_affinity_test.c` | check_result |
| 日志 | `smp_log_test` | **表内常注释掉** |

**磁盘上无** `*nexus*` / `single_elf_read` / `single_task` 一类陈旧叙述——不再索引。

---

## 8. 多架构

测例随 `ARCH=` 构建；PCI 等受 feature 门控。

---

## 9. 怎么跑

```bash
cd core && make ARCH=x86_64 config && make all && make run
```

确认 `config_*.json` features 含 `RENDEZVOS_TEST`。本篇未复测。

---

## 10. 限制与后续

- 10 槽上限。  
- 失败同步脆弱。
