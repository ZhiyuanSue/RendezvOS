## 评分方法

五个维度，每项满分 **100**；**总分 = 五项算术平均（四舍五入）**。

| 维度 | 含义 |
|---|---|
| 技术准确 | 与当前代码是否一致（以代码为准）；关键机制、常量、调用链有无说错说漏 |
| 内容与详略 | 是否讲清了「为什么这么设计」；重点是否够详、次要是否够略；有无空话 |
| 篇章架构 | 章节骨架是否顺：先读者需要的后读者暂时不需要的；层次是否混乱 |
| 篇章引用 | 对兄弟篇的引用是否准确、是否符合全书 nickname/编号惯例；有无生造名 |
| 词句可读 | 中文是否自然、有无电报体残句/生硬直译/歧义句；格式（表格、代码块、分隔）是否规范 |

**评分纪律**：只在确实通读过全文后打分，不凭印象造分。已在本轮可读性迭代中通读的篇目，评分依据为当轮通读笔记；细节因上下文压缩变糊的，补读后再填。已 review 篇目（README 双 `[x] [x]`）将在复审/专轮通读后补分。
